# HareetTashfer

HareetTashfer is a simple executable that converts the Arabic language to code by adding to each character.

## Table of Contents

- [Installation](#installation)
- [Usage](#usage)
- [Author](#author)
- [License](#license)

## Installation

1. Download the executable file from the [release page](https://github.com/Mina-Karam/HareetTashfer/releases).
2. Run the executable file.

## Usage

1. Fill each character with your code.
2. Write your code which needs to be coded.
3. Press "Convert".
4. [Optional] Press "Copy".
